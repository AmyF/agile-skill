# Runtime Structure

`.agile` contains `agile.yaml`, `status.yaml`, `feature-index.md`, `decision-log.md`, `recovery-log.md`, `changes/`, `features/`, and `releases/`. Change Requests have `CR-*.md` and `CR-*.record.yaml`. Do not create `.agile/scripts`, `.agile/schemas`, `.agile/bin`, or `.agile/tools`.
