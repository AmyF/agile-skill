# Agile Recovery Skill

## Purpose
Recover agile workflow state without losing auditability. Use for invalid state, rollback, Change Request impact, earliest impacted stage, pending revalidation, and recovery log drafting.

## Required References
Use `references/recovery-playbook.md`, `references/rollback-rules.md`, and `references/change-request-impact.md`.

## Forbidden Actions
Do not erase audit history, delete approved artifacts, edit approved versions in place, self-approve recovery, hide validation failure, or perform Git/GitHub rollback directly.
