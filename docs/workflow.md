# Workflow

Feature flow: initialized → prd_draft → prd_review → prd_approved → ddd_draft → ddd_review → ddd_approved → stories_in_progress → feature_acceptance_draft → feature_acceptance_review → feature_accepted.

Story flow: story_initialized → fid_draft → fid_review → fid_approved → tdd_draft → tdd_review → tdd_approved → acceptance_draft → acceptance_review → story_accepted.

BDD belongs to TDD. `.agile` is source of truth.
