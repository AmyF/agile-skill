# Test-Light

Test-light is a controlled exception for low-risk, non-behavioral UI/content/style changes. It still requires evidence, reviewer agreement or policy preauthorization, and a decision-log entry.

It must not be used for security, permissions, data, API behavior, business rules, state transitions, login, payment, critical journeys, deterministic game rules, scoring, save/load behavior, multiplayer, economy, or progression logic.
