# Execution Constraints

AI may draft artifacts, create runtime records, run deterministic gates, advance machine-verifiable states, and record explicit user approvals or preauthorizations.

AI must not self-approve product meaning, release readiness, waivers, or high-risk semantic changes. AI must not infer approval, edit approved versioned artifacts in place, hide drift, create `.github` files via `agile-run`, call GitHub APIs, or create scripts/schemas/tools inside `.agile`.
