# TDD Checklist

- Acceptance Criteria exist before TDD.
- Each criterion maps to at least one TDD flow or justified waiver.
- BDD scenarios are included for behavior that benefits from examples.
- App stories include relevant build, unit, integration, UI, accessibility, privacy, or data checks.
- Game stories include deterministic rule tests where possible and playtest/feel/performance evidence where relevant.
- Evidence IDs are ready to be recorded in `.agile`.
