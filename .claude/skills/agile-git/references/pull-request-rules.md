# Pull Request Rules

PR bodies must include Feature ID, Story ID when applicable, Change Request ID when applicable, Release ID when applicable, `.agile` artifact paths, evidence IDs, and gate status. Do not claim approval unless recorded from an external source.

When GitHub automation is enabled, PR creation belongs to `agile-github/scripts/create-pr.sh`; `agile-git` owns only branch, commit, push, and traceability metadata.
