# Automation Gates

Machine-verifiable gates run automatically and may advance state when all required checks pass. Gate outcomes are `pending`, `passed`, `failed`, or `waived`.

Waivers require a reason, owner/source, affected criteria, downstream risk, and timestamp. AI must not approve semantic waivers for itself.

Human confirmation is required for semantic approval, high-risk changes, release approval, policy exceptions, and waivers that change product meaning.
