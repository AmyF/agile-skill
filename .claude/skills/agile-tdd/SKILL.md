# Agile TDD Skill

## Purpose
Create and review TDD and BDD artifacts. BDD belongs to TDD and is not a standalone primary workflow stage.

## Required References
Use `references/checklist.md`, `references/tdd-flow-types.md`, `references/ui-tdd-rules.md`, `templates/TDD.md`, and `templates/BDD.md`.

## Forbidden Actions
Do not self-approve, treat BDD as a separate primary workflow state, modify approved versions in place, or use TDD-lite for high-risk behavioral changes.
