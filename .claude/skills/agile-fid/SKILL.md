# agile-fid

## Purpose
Create and review Feature Implementation Document artifacts. This skill owns FID content only and defers workflow state, approval recording, naming, and traceability enforcement to `agile-run`.

## Required References
Use `references/checklist.md` and `templates/FID.md`.

## Forbidden Actions
Do not self-approve, mark artifacts approved, modify approved versions in place, perform Git/GitHub operations, or bypass Change Request rules.
