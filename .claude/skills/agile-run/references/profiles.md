# Profiles

## App

Use for application features, UI, data, platform integration, privacy, permissions, accessibility, payments, accounts, and service behavior.

Default gates: build, relevant tests, acceptance evidence, traceability, data/privacy review when touched, accessibility notes when UI changes, Git metadata.

## Game

Use for gameplay features, rules, scoring, levels, controls, content, assets, performance, game feel, and playtest work.

Default gates: core loop or player goal, controls/feel expectation, deterministic rule tests where applicable, playtest evidence, screenshot/video/log evidence when useful, performance budget when relevant, asset/license notes, Git metadata.
