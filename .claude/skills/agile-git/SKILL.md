# Agile Git Skill

## Purpose
Own branch naming, commit message format, PR body conventions, merge gates, release branches, hotfix branches, and rollback workflow. It does not generate `.github` files.

## Forbidden Actions
Do not approve merges, bypass review, generate `.github`, call GitHub APIs, or treat GitHub as source of truth.
