# Execution Constraints

AI may draft artifacts, create runtime records, run deterministic gates, advance machine-verifiable states, and record explicit user approvals or preauthorizations.

AI must not self-approve product meaning, release readiness, waivers, merge approval, Issue close approval, or high-risk semantic changes. AI must not infer approval, edit approved versioned artifacts in place, hide drift, create `.github` files via `agile-run`, mutate GitHub outside `gh_controlled`, call direct GitHub APIs, or create scripts/schemas/tools inside `.agile`.
