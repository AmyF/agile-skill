# Git Workflow

Branch format: `{type}/{agile-id}/{slug}`. Commit format: `{type}({agile-id}): {summary}`.

`agile-git` may create/switch validated branches, create validated commits, push the current branch, and record Git refs back into `.agile` traceability.

PRs must reference `.agile` artifact paths, traceability, evidence, and gate status. Git and GitHub do not replace `.agile`.
