# Runtime Structure

`.agile` contains `agile.yaml`, `status.yaml`, `feature-index.md`, `decision-log.md`, `changes/`, `features/`, and `releases/`.

Change Requests have `CR-*.md` and `CR-*.record.yaml`. Feature and story directories contain runtime YAML, concise artifacts, traceability, and evidence. Do not create `.agile/scripts`, `.agile/schemas`, `.agile/bin`, or `.agile/tools`.
