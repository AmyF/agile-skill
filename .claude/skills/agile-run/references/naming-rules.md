# Naming Rules

Feature ID: `FEA-{YYYY}-{NNNN}-{slug}`. Story ID: `US-{NNN}-{slug}`. Change Request ID: `CR-{YYYY}-{NNNN}-{slug}`. Release ID: `REL-{YYYY}-{NNNN}`. Version: `vMAJOR.MINOR.PATCH`.

Use lowercase hyphenated slugs. Approval targets must be versioned files such as `prd/v1.0.0.md`, not `latest.md`.
